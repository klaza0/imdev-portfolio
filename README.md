# IMDEV Portfolio | Personal Developer Portfolio

The personal portfolio of **Ibrahim Montaser (IMDEV)**, Front-End & Mobile Developer. A dark, bilingual (Arabic and English) Next.js experience presenting projects, skills, and contact details with animation-driven transitions.

## Features

- Dark, minimal design with a custom theme.
- Bilingual Arabic and English typography.
- Animated transitions and scroll effects powered by GSAP.
- Technology brand icons via Simple Icons and Lucide.

## Built with

| Area | Technology |
| --- | --- |
| Framework | Next.js 16 |
| UI | React 19 + TypeScript |
| Animation | GSAP |
| Icons | Simple Icons, Lucide React |

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

```bash
npm run build   # Production build
npm start       # Serve the production build
```
